# 🚑 PULSE – IoT Smart Ambulance System

## 📌 Introduction

PULSE is an IoT-based Smart Ambulance System designed to improve emergency response and communication between ambulances and hospitals.

The system helps track the ambulance location, monitor patient vital information, send emergency SOS alerts, and notify hospitals during critical situations.

## 🎯 Objectives

- Provide faster emergency response
- Track ambulance location in real time
- Monitor patient vital information
- Send emergency alerts to hospitals
- Improve communication between ambulance and hospital
- Help hospitals prepare for incoming emergency patients

## 🛠️ Tools & Technologies Used

- HTML
- CSS
- JavaScript
- Python
- FastAPI
- IoT Sensors
- SQLite
- Google Maps

## ✨ Key Features

### 🚨 Emergency SOS
Allows the user to activate an emergency SOS and send the ambulance location to the backend.

### 📍 Live Location Tracking
Tracks the ambulance location using GPS and provides a Google Maps location link.

### ❤️ Patient Vital Monitoring
The system can handle patient vital information such as heart rate and SpO2.

### 🏥 Hospital Notifications
Hospitals can receive emergency notifications about the ambulance and patient.

### 🛏️ Hospital Bed Availability
The hospital dashboard provides information about available emergency beds.

### 📊 Hospital Emergency Dashboard
Provides hospitals with emergency information and ambulance-related updates.

### 👤 Login & Signup
Provides user authentication through login and signup functionality.

### 📄 Emergency Report
Emergency information and SOS history can be generated as a PDF report.

### 👤 User Profile
Users can save profile information such as name, city, age, education and profile photo.
